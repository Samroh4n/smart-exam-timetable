How graph coloring builds the timetable

Each subject is a node. Two subjects are joined by an edge when at least one student takes both, because those exams cannot run at the same time. Each color is one exam time slot. A valid coloring never gives connected subjects the same color, so no student ever has two exams at once. Fewer colors means fewer slots.
